# leadpagecarlos 2.0

Landing page de **Carlos Serra** com tema **Gótico Cósmico**: buraco negro em 3D no hero, letras góticas (blackletter), parallax e animações de rolagem. A página tem dois objetivos:

1. **Recrutadores** — conseguir uma vaga de estágio ou júnior.
2. **Clientes** — vender a criação de sites, com o contato indo direto para o WhatsApp.

> Projeto novo, feito do zero e separado do portfólio atual ([leadpagecarlos](https://github.com/carlosserra-a11y/leadpagecarlos)).
